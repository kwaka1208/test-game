# Code of Conduct

We want this project to be a friendly place where everyone can learn.
Mistakes are normal here.

## We do

- Be kind and patient.
- Assume good intentions.
- Give feedback about the work, not about the person.
- Say thank you when someone helps you.

## We do not

- Make fun of someone's English, skills, or mistakes.
- Use insulting, rude, or discriminatory words.
- Share other people's private information.

## If something goes wrong

Tell the team or the guild master. The team may edit or delete comments,
and close issues or pull requests that break this code.

This code of conduct is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/).
